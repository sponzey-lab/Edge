# Edge core

This crate owns the mio data plane and bounded runtime command processing.

Manual test-only entrypoints are indexed in [`../examples/source.md`](../examples/source.md).

| Path | Responsibility | Boundary / side effects |
| --- | --- | --- |
| `lib.rs` | HTTP proxy state machine, WebSocket handshake/tunnel transition, transport/runtime composition, bounded command queue, and snapshot mio runtime. | Performs nonblocking socket work; runtime command enqueue uses bounded `try_send` and returns stable typed rejection when full or closed; validates a complete HTTP/1.1 WebSocket upgrade handshake before tunneling, fail-closes an upstream socket-read, TLS-decode, resource-accounting, or timeout failure after response bytes begin rather than appending a second HTTP response; re-exports TLS contracts and publishes read-only runtime facts after listener registration. |
| `command_queue.rs` | Bounded FIFO storage and full detection for validated Core commands. | Does not dispatch commands, acknowledge them, own runtime policy, or perform I/O. |
| `client_response_charge_transaction.rs` | Client-response payload reservation, commit, resize, and rollback transactions. | Does not own response buffering, runtime policy, I/O, metrics/logs, or configuration. |
| `connection_table.rs` | Identity-indexed connection storage and terminal connection cleanup. | Does not own sockets, dispatch readiness, allocate tokens, mutate transition policy, or perform I/O. |
| `connection_transport.rs` | Client and upstream plaintext/TLS byte buffering and readiness projection facades. | Does not own socket registration, TLS session implementation, HTTP forwarding policy, runtime state transitions, or I/O. |
| `connection_state.rs` | Pure connection transition legality, readiness interests, event vocabulary, and timeout policy. | Does not mutate sockets or runtime tables, read clocks, perform I/O, or own command dispatch. |
| `connection_io.rs` | Per-connection transition wrapper and buffered HTTP request/upstream/client I/O state. | Does not register sockets, select routes, dispatch snapshot readiness, or perform direct I/O. |
| `http_forwarding_policy.rs` | Hop-by-hop header filtering, forwarded-header generation, exact-token WebSocket upgrade detection, bounded upstream-response header sanitization, and HTTPS redirect construction. | Normal request/response forwarding removes standard, legacy `Proxy-Connection`, and connection-nominated hop fields, then emits `Connection: close` on each final non-upgrade response because the runtime closes that client socket; chunked response framing retains `Transfer-Encoding` because bytes are streamed unchanged; validated WebSocket forwarding keeps only `Upgrade: websocket` and emits normalized `Connection: Upgrade`. Does not parse or write HTTP bytes, select routes, access configuration, or perform I/O. |
| `http_request.rs` | HTTP/1.1 request model, shared HTTP field-name/value and Host-authority validation, exact HTTP/1.1 request-line/transfer-length validation, limits, and incremental client request buffering. | Rejects unsupported version, missing/ambiguous Host authority, malformed/non-token field name or method, prohibited ASCII controls in a field value (while allowing horizontal tab) or request target, ambiguous/non-canonical request-line, or declared-body-length-mismatched input; validates the request line before the incremental buffer accepts a complete request. Does not read sockets, select routes, write upstream bytes, mutate runtime tables, or perform I/O. |
| `upstream_response_framing.rs` | Pure incremental HTTP/1.1 upstream response framing, transfer-length/chunk/trailer validation, and response-completion state. | Reuses the request field-value control-byte policy; rejects malformed status-lines, headers or trailers with prohibited ASCII controls, ambiguous framing, and premature EOF; does not read/write sockets, select routes, mutate runtime tables, emit observability, or perform I/O. |
| `tls_handshake.rs` | SNI certificate selection and the explicit TLS handshake state machine. | Pure Core state transition over snapshots and connection interest; does not open sockets, parse certificate files, or construct TLS sessions. |
| `tls_pending_payload_charge.rs` | TLS pending payload charge-slot synchronization over the generic ledger slot helper. | Does not own TLS session/socket bytes, transport I/O, runtime state, metrics/logs, or configuration. |
| `pending_socket_output.rs` | Buffered client socket bytes and explicit write acknowledgement tracking. | Has no socket registration or readiness ownership; delegates client/TLS encoding and stores only pending output bytes. |
| `payload_budget_ledger.rs` | Logical payload reservation, lifecycle accounting, generation checks, and fail-closed pressure hysteresis. | Does not own connection charge slots, emit metrics, register sockets, read clocks/configuration, or perform I/O. |
| `payload_charge_slot.rs` | Generic payload charge-slot lookup, synchronization, and release helpers. | Does not own connection state, socket I/O, metrics/logs, configuration, or ledger policy. |
| `pending_payload_ownership.rs` | TLS/WebSocket pending-byte ownership calculations for payload accounting. | Does not mutate charge slots or ledgers, perform socket I/O, emit metrics/logs, or access configuration. |
| `resource_admission_policy.rs` | Pure resource-pressure admission and upstream response-read interest decisions. | Does not mutate payload accounting, emit metrics, register sockets, read clocks/configuration, or perform I/O. |
| `resource_limits.rs` | Typed default connection, request, timeout, and response-buffer bounds. | Does not parse bootstrap configuration, admit connections, schedule timers, access runtime tables, or perform I/O. |
| `request_payload_charge.rs` | Request payload charge-slot growth and terminal release helpers. | Does not parse requests, own connection state, perform I/O, emit metrics/logs, or access configuration. |
| `tls_registry.rs` | Prepared client/server TLS session-factory identity, selection, and snapshot completeness validation. | Consumes adapter-provided factory ports; does not prepare TLS material, mutate runtime state, or perform I/O. |
| `tls_transport.rs` | Byte-oriented TLS session transport state, pending-byte delegation, and readiness projection. | Depends only on the TLS session port and connection-interest model; owns no socket, certificate, policy, or session-factory construction. |
| `timer_queue.rs` | Token-keyed deadline ordering and exact-expiry collection. | Does not acquire clocks, select poll timeouts, schedule runtime policy, register sockets, or perform I/O. |
| `token_allocator.rs` | mio token identity wrapper and recycled-token allocation state. | Does not register sockets, process readiness, access clocks/configuration, or perform I/O. |
| `upstream_attempt.rs` | One upstream request attempt's phase, terminal result, byte-progress validation, gateway timeout/error mapping, and response-started failure disposition. | Decides whether a synthetic gateway response remains legal; does not select/retry an upstream, own a socket, publish observability, or perform I/O. |
| `upstream_retry_charge_pair.rs` | Atomic reserve, commit, and failure release for upstream-request and retry-replay payload charge pairs. | Does not own connection lifecycle, select an upstream, perform I/O, emit metrics/logs, or access configuration. |
| `write_buffer.rs` | Capacity-safe managed byte appends, acknowledgement cursor movement, and completed-buffer reset. | Does not perform socket I/O, account payload resources, select a transport, or own connection lifecycle. |
| `worker_event_queue.rs` | Worker completion-event vocabulary and FIFO handoff storage. | Does not spawn workers, mutate runtime/config state, dispatch commands, or perform I/O. |
