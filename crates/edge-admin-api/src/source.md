# Admin API contract

This directory defines versioned Admin API request, response, session, and
read-model contracts. It has no HTTP listener implementation.

| Path | Responsibility | Boundary / Side effects |
| --- | --- | --- |
| `http_envelope.rs` | Admin HTTP request/response envelope parse and render contract. | Pure supplied-text/value conversion; no listener, socket, environment, or concrete I/O. |
| `http_dispatch.rs` | Admin API v1 root route dispatch and unbound-mutation gate. | Uses supplied request/session/snapshot and delegates to handlers; preserves auth/CSRF route gating without implementing handler, lifecycle, Core, config, certificate, or I/O behavior. |
| `error_response.rs` | Stable Admin API error value, JSON rendering, and HTTP status mapping. | Pure typed-error conversion; retains code/message/hint/request-id and exposes no secret values. |
| `session_auth.rs` | In-memory Admin session, CSRF, and bootstrap login authentication. | Receives supplied hash/session values only; no secret storage, cookies, listener, or external I/O. |
| `stateful_session_http.rs` | Setup, login, logout, and pre-setup mutation route adaptation. | Uses supplied session and secret-store ports plus HTTP envelopes only; does not operate a listener, mutate config/Core state, or expose secret values. |
| `status_read_model.rs` | Admin status, health, and upstream-health snapshot projection. | Pure supplied snapshot conversion; no authentication, probe dispatch, Core mutation, or runtime I/O. |
| `status_http.rs` | Read-only status HTTP adaptation. | Renders supplied desired/active snapshots and an optional resource snapshot only; does not collect resource state, mutate lifecycle/Core state, authenticate, or perform I/O. |
| `health_response_http.rs` | Admin health, operational-probe, and upstream-health HTTP adaptation. | Consumes supplied snapshots/read ports and session state only; operational probes expose no config details, and it does not schedule probes, operate a listener, or mutate Core state. |
| `runtime_metrics_read_model.rs` | Runtime metric summary and series JSON projection. | Renders supplied metric snapshots only, preserving bounded response groups; does not read metrics, authenticate, dispatch HTTP, operate a listener, or perform concrete I/O. |
| `runtime_metrics_http.rs` | Read-only runtime-metrics HTTP adaptation. | Uses supplied session and metric-reader port with the bounded projection; rejects query parameters and does not collect metrics, mutate runtime/Core state, or perform I/O. |
| `audit_read_model.rs` | Bounded audit query parsing, cursor codec, and audit-page JSON projection. | Pure allowlisted query and supplied-ledger conversion; no audit persistence, authentication, listener I/O, or secret values. |
| `audit_and_log_read_http.rs` | Read-only audit query and recent-log HTTP adaptation. | Uses supplied session, ledger-reader, and event values; preserves bounded query and secret-free JSON contracts, and does not persist audit/log data, mutate lifecycle/Core state, or perform I/O. |
| `admin_json_contract.rs` | Admin API v1 JSON response rendering, string escaping, and supplied-body field parsing. | Pure supplied-value conversion; does not authenticate, dispatch handlers, access environment state, operate a listener, or perform concrete I/O. |
| `config_source_schema.rs` | Admin config snapshot validation and source parse/error projection. | Uses supplied config text/snapshots and pure application parser/validator only; does not render HTTP/JSON, mutate lifecycle state, perform I/O, or access environment state. |
| `config_read_http.rs` | Read-only config get, validate, and diff HTTP adaptation. | Uses supplied sessions/snapshots and pure config schema functions only; does not apply or persist revisions, audit, send Core commands, or perform I/O. |
| `config_mutation_http.rs` | Config apply and rollback HTTP adaptation. | Uses supplied session, lifecycle, and bounded Core-command port only; preserves CSRF/error behavior and does not implement config policy, persistence/audit policy, Core command processing, or I/O. |
| `certificate_read_http.rs` | Stored certificate list and member HTTP adaptation. | Uses supplied session and certificate-store read port only; preserves status projection and secret-free responses, and does not import, issue, renew, install, mutate storage, or perform I/O. |
| `manual_certificate_import_http.rs` | Manual certificate import HTTP adaptation. | Uses supplied session, revision, and validation/store/audit/Core ports only; preserves CSRF, request identity, compensation/error behavior, and does not issue, renew, or use ACME/HTTP-01 automation. |
| `support_bundle_api.rs` | Fixed-allowlist support-bundle authorization, use-case adaptation, safe receipt projection, and HTTP response adaptation. | Uses supplied session and collector ports only; does not permit caller-selected artifacts/bounds or concrete I/O, and excludes archive/redaction internals from its response. |
| `trust_bundle_http.rs` | Trust-bundle list, import, and delete HTTP adaptation. | Uses supplied session and typed service only; preserves CSRF, material-size, and secret-free response rules, and does not own storage, validation, audit policy, lifecycle/Core mutation, or I/O. |
| `proxy_host_request_model.rs` | Proxy-host request values and pure conversion into the domain ProxyHost model. | Does not parse JSON, read snapshots, apply config, dispatch HTTP, perform I/O, or access environment state. |
| `proxy_host_request_decoder.rs` | Proxy-host supplied-JSON decoding and nested upstream/retry/passive-health/health-check policy normalization. | Reuses the shared Admin JSON field helpers and malformed-field contract; does not read snapshots, apply config, dispatch HTTP, perform I/O, or access environment state. |
| `proxy_host_member_path.rs` | Admin API v1 proxy-host get/update/delete member-path parsing. | Purely translates a supplied path into a `ProxyHostId` or stable route error; does not dispatch HTTP, parse JSON, read snapshots, apply config, perform I/O, or access environment state. |
| `proxy_host_read_http.rs` | Read-only proxy-host list and member HTTP adaptation. | Uses supplied session and immutable snapshot with existing path/projection helpers; does not mutate config, persist/audit, send Core commands, or perform I/O. |
| `proxy_host_mutation_http.rs` | Proxy-host create, update, and delete HTTP adaptation. | Uses supplied session, lifecycle, and bounded Core-command port with existing request/path helpers; preserves CSRF/error behavior and does not implement proxy-host policy, persistence/audit policy, Core command processing, or I/O. |
| `proxy_host_snapshot_projection.rs` | Public immutable proxy-host response schema and config-snapshot projection. | Reads only supplied snapshot values and creates response values; does not parse request JSON, apply config, dispatch HTTP, perform I/O, or access environment state. |
| `lib.rs` | Admin handlers, schemas, authentication checks, operational probe payloads, and support-bundle read model. | Pure API adaptation over supplied ports and snapshots; delegates JSON response rendering/body-field parsing to `admin_json_contract.rs`, and support bundle creation uses a fixed allowlist/bounds with a secret-free receipt. |
