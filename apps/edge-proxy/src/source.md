# Edge proxy bootstrap

This directory wires typed bootstrap configuration and adapters to the mio Core.
It owns process and HTTP-server boundaries but not routing or policy decisions.

| Path | Responsibility | Boundary / Side effects |
| --- | --- | --- |
| `main.rs` | Process bootstrap, backup/restore/audit maintenance CLI dispatch, operational probe CLI, and Unix SIGTERM watcher. | Reads environment at bootstrap only; sends acknowledged Core commands outside signal context and emits secret-free result JSON. |
| `process_mode.rs` | Typed maintenance and operational-probe command parser. | Parses arguments only; requires explicit deployment/identity/artifact/passphrase-file/recovery inputs for maintenance operations and never reads or exposes secret values. |
| `upgrade_lifecycle.rs` | Offline upgrade and recovery maintenance execution. | Selects only the explicit systemd or Compose journaled helper boundary and renders stable secret-free result JSON; does not parse arguments, read environment values, or start the proxy runtime. |
| `startup_logging.rs` | Secret-free bootstrap audit, process, config-resolution, and upstream-TLS startup log projection. | Renders supplied facts only; does not alter startup ordering, read environment state, prepare TLS, or enable certificate automation. |
| `admin_http.rs` | Loopback Admin HTTP server and request/API adapter wiring. | Enforces bounded UTF-8 request reads and rejects invalid or ambiguous `Content-Length` before API parsing; reports one atomic snapshot-apply acknowledgement for hot config mutations; support-bundle paths are bootstrap-wired rather than request-supplied, trust-bundle persistence/audit lives in `admin_trust_bundles.rs`, while shared Core-published status storage lives in `runtime_status.rs`. |
| `admin_audit.rs` | Shared Admin audit context, stable failure response, JSON audit-identity projection, and terminal durable-audit completion. | Handles only supplied typed requests/responses and ledgers; does not authenticate, route, apply configuration, or change audit ordering/semantics. |
| `admin_log_ingestion.rs` | Admin runtime access/error-log receiver and bounded-buffer collector threads. | Receives supplied runtime events only; stops on channel close or buffer-lock failure and does not parse HTTP, choose log policy, emit records, or access environment state. |
| `admin_static_assets.rs` | Embedded Admin Web UI GET asset response projection. | Maps only supplied GET request paths to fixed embedded assets and content types; does not parse HTTP, authenticate, choose cache policy, or access network state. |
| `admin_trust_bundles.rs` | File-backed Admin trust-bundle persistence, retained-revision protection, event projection, and durable-audit completion adapter. | Receives typed, already-authenticated requests only; keeps trust material out of responses/logs and does not parse HTTP, route requests, or enable certificate automation. |
| `runtime_status.rs` | Shared Core-published operational, upstream, and resource status adapters. | Provides bounded lock/try-lock snapshot publication plus drain-transition observability; contains no HTTP parsing, routing, or network I/O. |
| `bootstrap.rs` | Bootstrap-only environment parsing and data-layout setup. | Filesystem/environment boundary. |
| `bootstrap_audit.rs` | Bootstrap audit-admission and fail-closed authoritative-state adapters. | Holds supplied startup state and returns only `Unknown` for unavailable authoritative facts; does not access the ledger, decide audit policy, or perform I/O. |
| `health_runtime.rs` | Bootstrap-wired health worker lifecycle, bounded probe coordination, passive observations, prepared TLS health transport, and secret-free observability bridge. | Runs outside the mio hot path with bounded channels/worker limits; uses supplied Core, TLS, metric, and log adapters only and does not read environment state or change routing policy. |
| `sigterm_drain.rs` | SIGTERM observation and bounded Core drain command adapter. | Its Unix signal handler only sets an atomic flag; outside signal context, the watcher delivers one drain command and emits a secret-free rejection event without directly mutating Core state. |
| `operational_probe.rs` | Local Admin liveness/readiness probe CLI adapter. | Connects only to an explicitly supplied loopback Admin address with bounded I/O and returns stable process exit codes without logging response data. |
| `https_listener_selection.rs` | Bootstrap-only selection of configured HTTPS listeners and manual/file-backed route certificate references. | Reads only supplied config snapshots, parses configured listener bind values, and never issues/renews certificates, binds sockets, builds TLS factories, accesses environment state, or performs certificate-store I/O. |
